# Users

- **Date:** 2026-10-15
- **Status:** accepted
- **Instructions:** [`docs/instructions/design.md`](../instructions/design.md) (Homescreen, Users screen)

## Context

The user asked for users, with a default one, editable in a users section opened from a button on top of the
homescreen, and authorized updating design.md to match (done: "Button on top" and a "Users screen" section).

## Decision

- **What belongs to a user:** consumptions (`logs.userId`) and targets (`targets.userId`). Foods are shared (a
  household eats the same foods), and so is config (day start, dashboard style).
- **Schema v10:** `users` table (`++id, name`); `logs` gets a `[userId+datetime]` index, `targets` a `userId` index.
  The upgrade creates user 1 "Default" and gives it all existing consumptions and targets. A new database gets the
  same default user (Dexie `populate`).
- **Current user:** its own config row (`key: 'currentUser'`), so saving the Config screen (which rewrites `main`)
  can't clear it. `getCurrentUser()` falls back to the first user if the row is missing or stale.
- **Homescreen:** a small "👤 name" pill above the window header, right-aligned. Consumptions and Targets show the
  user's name under the title.
- **Users screen (`#/users`):** tap a row to switch; ✎ opens a sheet to rename; "+ add user" last, and a new user
  becomes current. Names are required and unique (case-insensitive). Delete is a two-step in-sheet confirmation
  that states how many consumptions go with it; it's hidden when only one user is left.
- **Export v7:** includes `users`. Importing an older file puts everything under the default user.

## Alternatives considered

- **Per-user foods** — would duplicate shared foods and recipes; foods are facts about food, not about a person.
- **Per-user config** — possible later (e.g. dashboard style per person); not asked for.
- **Tap a row to edit, switch from inside the sheet** — switching is the frequent action, so it gets the tap.

## Consequences

- Deleting a user deletes their consumptions and targets (stated before confirming).
- No profiles or authentication: anyone with the device can switch user.
