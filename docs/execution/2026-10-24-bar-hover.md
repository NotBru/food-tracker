# Dashboard bars: hovering shows the amount under the cursor

- **Date:** 2026-10-24
- **Status:** accepted
- **Instructions:** [`docs/instructions/design.md`](../instructions/design.md) (Homescreen dashboard); request in chat

## Context

The user: "Hovering the cursor over the dashboard's bars should display the amount over which the cursor is".

## Decision

- Dashboard style "bars" (`Home.jsx BarRow`): with a mouse over a bar that has a target, a thin line at the cursor
  and a small label above it with the amount at that point, in the row's unit ("1576 kcal"). It goes when the
  mouse leaves.
- The amount is the bar's own scale run backwards: `calc.js barScale` returns a function with an `at` (% → amount).
- Mouse only (`pointerType`): a tap still opens the breakdown. Bars without a target (the neutral full bar) show
  nothing, as they have no scale. The hover target reaches 6 px above and below the 10 px bar.

## Alternatives considered

- Gauges too: not asked for ("bars"); the same `at` would work from the pointer's angle.

## Consequences

- None beyond the hover itself.
