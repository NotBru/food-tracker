# Fact-check, part B: report lines 38–45, "In animal foods, fat swings energy by a third or more"

Report: `docs/notes/reports/Nutrient content variability.md`. Checked 2026-10-22 against primary sources. The report was not edited.

Method notes:
- **PMC.** PMC returned a reCAPTCHA for PMC9469852, so that full text was read from the Europe PMC full-text XML (`https://www.ebi.ac.uk/europepmc/webservices/rest/PMC9469852/fullTextXML`).
- **SR28.** SR28 values were recomputed from the raw `NUT_DATA.txt` in the official `sr28asc.zip`. The local copy is in `data/raw/sr28asc/`, and the report's URL returns HTTP 200 for the same zip. CV is computed as SE·√n / mean. Note that SR28 publishes SE and n, not CVs, so "SR28 gives … CV" means "CV derived from SR28 SE and n".
- **Slotte 1996.** The full text came from the ICES library PDF (`https://www.ices.dk/sites/pub/CM%20Doccuments/1996/H/1996_H11.pdf`) and the NVA record that the handle resolves to.
- **Teagasc and UVM.** Both were read through their DSpace REST APIs, because the HTML entity pages are JavaScript apps and the Teagasc one also returned 403.
